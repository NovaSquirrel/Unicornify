A Python 3 update of [Unicornify](https://web.archive.org/web/20101226060527/http://unicornify.appspot.com/) which was originally written in Python 2 by Benjamin Dumke-von der Ehe.

See also [a Go version](https://github.com/balpha/go-unicornify) and [a free API](https://unicornify.pictures/) providing Unicornify as a web service.
